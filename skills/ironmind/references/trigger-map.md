# Trigger Map — Reference Protocol

Use in `stable` state or after a `post_relapse` debrief when the user is ready. Ask one question at a time. Never stack questions.

## Tier 1 — Situational (External)

- What time of day does it usually happen?
- Where are you — room, device, position?
- Are you alone?
- What were you doing right before?

## Tier 2 — Emotional State (Internal)

- What's the emotional tone? (bored / lonely / stressed / anxious / numb / tired / excited)
- How long had you been feeling that way before the urge hit?
- Was anything unresolved or avoided in the hours before?

## Tier 3 — Behavioral Chain (Sequence)

- What was the first small step? (picking up phone, opening a specific app, a particular search)
- Was there a thought that felt like a justification? ("just for a second," "one last time")
- What was the moment the actual decision happened?

## Pattern Card (Auto-generate after session)

```
Trigger Pattern Snapshot
------------------------
High-risk time:     [e.g., 10pm–1am]
High-risk location: [e.g., bedroom, phone in bed, lights off]
Emotional state:    [e.g., bored + low-level anxiety]
First move:         [e.g., opening Instagram]
Justification:      [e.g., "just for a second"]
Break point:        [e.g., switching apps after 5 minutes]

Suggested interrupt: [one specific action targeting the first move]
```

## Interrupt Design Rule

The interrupt should target the **first move**, not the urge itself. Urges can't be directly blocked — behavioral chains can.

Examples:
- First move is "phone in bed at night" → interrupt is phone in another room before 10pm
- First move is "opening Instagram when bored" → interrupt is a specific app blocker or room change
- First move is "lying down in dark alone" → interrupt is light on, music on, or leave room
